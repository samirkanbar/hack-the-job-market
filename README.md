# applIRL

A 2-sided platform connecting students to employers through real-world events and quests.

## Features

### Student Side
- View and register for quests (hackathons, networking events, career fairs)
- Earn tokens and badges by attending events
- Track Hustle Stat based on event participation
- Build profile through real-world interactions

### Employer Side
- Create and manage events
- View matched students based on quest completion
- See student engagement quality and endorsements
- Filter high-priority candidates who demonstrated initiative

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open http://localhost:5173 in your browser

## Tech Stack
- React 18
- React Router 6
- Vite
- CSS (no framework)
